4  Hypothesis Testing

TipDefinition: Statistical inference

Statistical Inference refers generally to the methods by which one makes inferences or generalizations about a population and its parameters based on statistics calculated from sample data. These methods can be classified broadly into three forms:

  • Point estimation is the process by which an estimator of an unknown parameter, or function of parameters, is chosen and evaluated.

  • Interval estimation is the process by which an observed value of a statistic and the statistic’s probability distribution are used to create a range of plausible values of an unknown parameter, or function of parameters.

  • Hypothesis testing is the process by which an observed value of a statistic and the statistic’s probability distribution are used to evaluate the plausibility of a statement made about the unknown value of a parameter.

We typically want to use the information contained in sample data to make inferences/decisions about a population and/or its paramters. So far, we’ve talked about how to find estimators, and how to evaluate the “goodness” of these estimators. Sometimes we are interested in not only estimating the parameter, but also in evaluating the plausibility of some statement about the unknown parameter. For example, we might be interested in asking questions like:

  • does a new vaccine decrease the incidence rate of the flu?
  • does the addition of citric acid to water extend the life of cut roses?
  • does one section of a course understand the material in a class better than another section?
  • does a professional development program for teachers increase student learning?

In each case, there is an underlying parameter \(\theta\):

  • incidence rate of the flu
  • cut rose lifespan
  • “amount” of student understanding
  • “amount” of student learning

The goal of hypothesis testing is to determine if \(\theta\) changes in specified ways when an element of the system is changed. For example, does the incidence rate of the flu decrease when the new vaccine is used in place of the old vaccine? Does the lifespan of a cut rose increase when citric acid is added to the water? A hypothesis test is a rule used to choose between two complementary hypotheses. Just as we saw that not all estimators are created equally, not all hypothesis tests are equally “good.” We’ll spend the next few weeks discussing hypothesis tests, including new definitions and notation, choosing between tests, and two methods for deriving hypothesis tests.

4.1 Elements of a Hypothesis Test

Hypotheses

The objective of a hypothesis test is to answer a question about an unknown population parameter \(\theta\), which can take on any value in the parameter space, \(\Theta\). Remember that the parameter space gives all of the possible values of the parameter.


The parameter space \(\Theta\) is partitioned into two complementary spaces: \(\Theta_0\) and \(\Theta_a\). Because this is a partition, we assume that \(\Theta=\Theta_0 \cup \Theta_a\) and \(\Theta_0 \cap \Theta_a = \emptyset\). These two complementary spaces are used to form the corresponding complementary hypotheses for the question we wish to answer:

  • Null hypothesis (H\(_0\)): the unknown \(\theta \in \Theta_0\)

    The null hypothesis can be thought of as the “no change” hypothesis. It is often a statement that changing the element of the system does not result in a change in the parameter \(\theta\) (though not always).

  • Alternative Hypothesis (H\(_a\)): the unknown \(\theta \in \Theta_a\)

    The alternative hypothesis is the complement of the null hypothesis. This means it is often the “change” hypothesis; changing the element of the system does indeed result in a change in the parameter \(\theta\).

Example: Are more than half of all “Henry Moore” prints for sale on auction sites fake?

What are the population parameter, null and alternative hypotheses, and the parameter space for the research question? What are \(\Theta_0\) and \(\Theta_a\)?









Test Function

A hypothesis test is a rule by which the data are used to choose between H\(_0\) and H\(_a\). This rule is an indicator function that will lead us to one of two decisions: \[ \phi(X_1,\dots, X_n) = \left \{ \begin{array}{ll} 1 & \hbox{reject H}_0 \\ 0 & \hbox{fail to reject H}_0 \end{array} \right . . \]

The set \(\{X_1,\dots,X_n\}\) such that \(\phi(X_1,\dots, X_n) = 1\) is the rejection region.

4.2 Hypothesis Testing Strategy

Our overall strategy is: Minimize P(Type II error) subject to a bound on P(Type I error).

That is, we first specify the P(Type I error) we are willing to tolerate, and then (if possible) find the test that has the minimum P(Type II error). Equivalently, we find the test with the maximum sensitivity for a given level of specificity.




To do this, we’ll use the power function.

TipDefinition: size-\(\alpha\) test

A test \(\phi\) is a size-\(\alpha\) test if its power function satisfies \[ \max_{\theta \in \Theta_0} power(\theta) = \alpha \]

TipDefinition: level-\(\alpha\) test

A size-\(\alpha\) test is a level-\(\alpha\) test. For any set of null and alternative hypotheses:

\[\begin{eqnarray*} \{\hbox{set of size-$\alpha$ tests}\} &\subset& \{\hbox{set of level-$\alpha$ tests}\} \\ &\subset& \{\hbox{set of level-$\alpha^*$ tests, $\alpha^* \geq \alpha$}\} \end{eqnarray*}\]

4.3.1 Constructing Likelihood Ratio Tests

We can use the “likelihood” of the two hypotheses given the data to choose between the two alternatives. Most of the time, however, we don’t know \(\theta\) so we’ll need to estimate it. What type of estimator do you think we’ll use?

TipDefinition: Likelihood Ratio Test

Consider testing H\(_0: \theta \in \Theta_0\) versus H\(_a: \theta \in \Theta_a\). The likelihood ratio test statistic is


\[ \lambda(x_1,\dots,x_n) = \hbox{\hspace{150mm}} \]


The likelihood ratio test (LRT) is any test that has a rejection region of the form \(\lambda(x_1,\dots,x_n) \leq k\), where is \(k\) is chosen to achieve the desired signficance level, with \(0 \leq k \leq 1\). That is, the LRT has the form \(\phi(X_1,\dots,X_n) = \left\{\begin{array}{ll} 1 & \lambda(x_1,\dots,x_n) \leq k \\ 0 & \hbox{elsewhere}\end{array}\right.\).

TipFinding LRTs
  1. Specify hypotheses: H\(_0: \theta \in \Theta_0\) versus H\(_a: \theta \in \Theta_a\)
  2. Specify the likelihood function: \[L(\theta|x_1,\dots,x_n) = L(\theta|\mathbf{x}) = f(\mathbf{x};\theta) = f(x_1,\dots,x_n;\theta) = \prod_{i=1}^n f(x_i;\theta)\]
  3. Find \(\max_{\theta \in \Theta_0} L(\theta|\mathbf{x}) = L(\hat\theta_0|\mathbf{x})\)
  4. Find \(\max_{\theta \in \Theta} L(\theta|\mathbf{x}) = L(\hat\theta_{\hbox{\tiny{MLE}}}|\mathbf{x})\)
  5. Calculate \(\lambda(\mathbf{x}) = \frac{L(\hat\theta_0|\mathbf{x})}{L(\hat\theta_{\hbox{\tiny{MLE}}}|\mathbf{x})}\)
  6. Find a critical value for \(\lambda(\mathbf{x})\) to ensure a signficance level of \(\alpha\)
  7. Carry out the test and report the conclusion in context

4.3.2 Approximate Distribution Theory for LRTs

Under some “regularity” conditions on the distribution of the data, the large sample distribution of the LRT statistic is \(\chi^2\).

TipTheorem

If \(X_1,\dots, X_n\) are iid with pdf/pmf \(f(x;\theta)\) and \(\lambda(x_1,\dots,x_n)\) is the likelihood ratio test statistic for testing H\(_0: \theta \in \Theta_0\) versus H\(_a: \theta \in \Theta_a\), then under regularity conditions on \(f(x;\theta)\) under H\(_0\), as \(n \rightarrow \infty\): \[ -2\ln[\lambda(\mathbf{x})] \xrightarrow{D} \chi^2_{k} \] where \(k\) = [# free parameters for \(\theta \in \Theta\)] - [# free parameters for \(\theta \in \Theta_0\)]. This yields the test with (approximate) significance level \(\alpha\): \[ \phi(X_1,\dots, X_n) = \left \{ \begin{array}{ll} 1 & -2\ln[\lambda(\mathbf{x})] > \chi^2_{k,\alpha} \\ 0 & \hbox{elsewhere} \end{array} \right . \]

4.4.1 The Neyman-Pearson Lemma

This idea of constructing the rejection region by including points that contribute the most power per level is the motivation for the Neyman-Pearson Lemma.


TipTheorem: Neyman-Pearson Lemma

Consider testing H\(_0: \theta=\theta_0\) versus H\(_a: \theta = \theta_1\), where \((X_1,\dots, X_n) \sim f(x_1,\dots, x_n|\theta)\). For a constant \(k>0\), let \[ \phi(X_1,\dots, X_n) = \left \{ \begin{array}{ll} 1 & f(x_1,\dots,x_n|\theta_1) > k f(x_1,\dots, x_n|\theta_0) \\ 0 & f(x_1,\dots,x_n|\theta_1) < k f(x_1,\dots, x_n|\theta_0) \end{array} \right . \] and let \(\alpha\) be defined as \[ \alpha = P(\phi(X_1,\dots, X_n) = 1 |\theta=\theta_0). \] Then, \(\phi(X_1,\dots, X_n)\) is most powerful for testing H\(_0\) versus H\(_a\) at level \(\alpha\).

Example: Let \(X_1,\dots,X_n\) be a random sample from the exponential\((\theta)\) distribution. We want to test H\(_0: \theta = \theta_0\) versus H\(_a: \theta=\theta_1\) where \(\theta_1 > \theta_0\).





















Example: Let \(X_1,\dots, X_n\) be Normal\((\mu,\sigma^2)\) random variables where \(\sigma^2\) is known. We want to test H\(_0: \mu = \mu_0\) versus H\(_a: \mu=\mu_1\) where \(\mu_1 > \mu_0\).





















The test we just derived does not depend on \(\mu_1\) The same test is most powerful for every \(\mu_1 > \mu_0\) (though the power will differ for different values of \(\mu_1\)). If a test has this property it is called uniformly most powerful (UMP).

TipDefinition: Uniformly Most Powerful (UMP) Tests

A test is a uniformly most powerful (UMP) test of size \(\alpha\) if it has size \(\alpha\) and if for all parameter values in the alternative spae it has maximum power relative to all rejection regions of size \(\alpha\).

In practice, the Neyman-Pearson Lemma may be used to find UMP tests for composite alternative hypotheses by first finding the NP test for a particular simple alternative, and then showing the test does not depend on the specified alternative value.

Example: Let \(X_1,\dots, X_n\) be Normal\((\mu,\sigma^2)\) random variables where \(\sigma^2\) is known. We want to test H\(_0: \mu = \mu_0\) versus H\(_a: \mu=\mu_1\) where \(\mu_1 > \mu_0\).







Like MLEs (and LRTs), the NP Lemma guarantees that most powerful tests (if they exist) will be functions of sufficient statistics. The NP Lemma says the test \[ \phi(X_1,\dots,X_n) = \left \{ \begin{array}{ll} 1 & f(x_1,\dots,x_n|\theta_1) > k f(x_1,\dots, x_n|\theta_0) \\ 0 & f(x_1,\dots,x_n|\theta_1) < k f(x_1,\dots, x_n|\theta_0) \end{array} \right . \] is most powerful.

  • 1\(^{st}\) extension: The NP test is uniformly most powerful for testing H\(_0: \theta = \theta_0\) versus H\(_a: \theta < \theta_0\) (its size is still \(\alpha\)).

4.4.3 Monotone Likelihood Ratios

The monotone likelihood ratio is a condition that, when it holds, lets us find UMP tests for 1-sided alternatives without going through the NP Lemma + Extensions process.

TipDefinition: Monotone Likelihood Ratio

A joint pdf/pmf \(f(x_1,\dots,x_n|\theta)\) has a monotone likelihood ratio (MLR) in the statistic \(T=t(X_1,\dots,X_n)\) if, for any two values of the parameter \(\theta_2 > \theta_1\), the ratio \(f(x_1,\dots,x_n|\theta_2)/f(x_1,\dots,x_n|\theta_1)\) depends on \((x_1,\dots,x_n)\) only through the function \(t(x_1,\dots,x_n)\) and this ratio is a non-decreasing function of \(t(x_1,\dots,x_n)\).

Note: if the ratio is non-increasing in \(t(x_1,\dots,x_n)\) it can be made non-decreasing.

Example: Let \(X_1,\dots, X_n\) be iid Poisson\((\lambda)\) random variables.












TipTheorem: Karlin-Rubin (Greater than)

Consider testing H\(_0:\theta \leq \theta_0\) versus H\(_a: \theta > \theta_1\). Suppose that \(T\) is a sufficient statistic for \(\theta\) and the family of pdfs/pmfs of \(T\) has an MLR. Then, for any \(t_0\), the test that rejects H\(_0\) if and only if \(T > t_0\) is a UMP level-\(\alpha\) test, where \(\alpha = P(T > t_0|\theta_0)\).

4.5 P-values

So far, we’ve been dealing with tests with a pre-specified significance level. That is, our tests have the form \(\phi(X_1,\dots,X_n) = \left \{ \begin{array}{ll} 1 & T(X_1,\dots,X_n) > k_{\alpha} \\ 0 & T(X_1,\dots,X_n) \leq k_{\alpha} \end{array}\right.\) where \(\alpha=P(T>k_{\alpha}|\hbox{H}_0 \hbox{ true})\). The numerical value of \(\alpha\) is chosen arbitrarily (or by tradition), and different researchers may disagree about what value of \(\alpha\) should be used. This can lead to an uncomfortable situation: two researchers come to different conclusions, even with the same set of data. However, if the researchers use the same test statistic, we can overcome this problem by reporting the results in terms of the p-value of the test.

TipDefinition: p-value

If \(W(X_1,\dots,X_n)\) is a test statistic, the p-value, or attained significance level, is the smallest level of significance \(\alpha\) for which the observed data indicate that the null hypothesis should be rejected. The smaller the p-value, the more compelling is the evidence that the null hypothesis should be rejected.

Example: Let’s go back to the 14th and Superior roundabout example. In that case, our LRT was \[ \phi_\alpha(X_1,\dots,X_n) = \left \{ \begin{array}{ll} 1 & W(X_1,\dots,X_n) > k_{\alpha} \\ 0 & W(X_1,\dots,X_n) < k_{\alpha} \end{array} \right . . \] Previously, we set \(\alpha=0.05\). We could have chosen many different signficance levels:













Notice that as \(\alpha\) decreases, the critical value \(k_{\alpha}\) increases, making it more difficult to reject the null hypothesis. This makes sense, because we are reducing our chance of making a Type I error. With the data observed, our test statistic was 6.776, and at \(\alpha=0.05\), we rejected the null hypothesis. However, if we had used a different \(\alpha\) value, we would have reached a different conclusion.

To avoid this issue, p-values are often reported so that researchers (or, maybe more importantly, consumers of the research) can reach their own conclusions about the significance of the test results. The p-value of the test is the smallest value of \(\alpha\) for which we would reject H\(_0\). That is, it is the smallest value of \(\alpha\) for which \(\phi(X_1,\dots,X_n) = 1\). For example, if our p-value=0.024, then 0.024 is the smallest value \(\alpha\) could be, and we would still reject H\(_0\). For a test with significance level \(\alpha\), we could re-write the test rule as \[ \phi_ \alpha(X_1,\dots,X_n) = \left \{ \begin{array}{ll} 1 & \hbox{p-value} < \alpha \\ 0 & \hbox{p-value} > \alpha \end{array} \right . \] P-values are convenient because the end user of the test doesn’t need to look up critical values in a table. Note that smaller p-values indicate greater evidence against H\(_0\) and larger p-values indicate lesser evidence against H\(_0\).
