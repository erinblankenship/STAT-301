3  Evaluating Estimators

For a particular estimation problem there may be several (maybe even many) competing estimators. We’ll spend the next bit of time answering the questions:

  • Are some estimators better, in some sense, than others?
  • If so, in what sense?

Right off, we acknowledge that some estimators are indeed better than others. For example, if \(X_1,\dots, X_n \sim\) Poisson(\(\lambda)\) we have two competing estimators for \(\lambda\): \(\bar X\) and \(S^2\) (why?). It turns out that \(\bar X\) is a better estimator than is \(S^2\). To see why, we’ll start by discussing some properties of estimators that will help us decide which are better.

3.1 Criteria for Good Estimators

Tip“Good” estimators

A good estimator is unbiased. An estimator \(\hat\theta\) is an unbiased estimator of \(\theta\) if: \[\hbox{E}(\hat\theta) = \theta.\] In addition to being unbiased, a good estimator has small variance. If \(\hat\theta_1\) and \(\hat\theta_2\) are unbiased estimators of \(\theta\), then \(\hat\theta_1\) is a better estimator (or, a more efficient estimator) than \(\hat\theta_2\) if: \[\hbox{Var}(\hat\theta_1) < \hbox{Var}(\hat\theta_2).\]

Remember that estimators are statistics, and are themselves RVs. As such, they have their own distributions.








If an estimator of a parameter (or function of parameters) is unbiased and has the smallest variance of all possible unbiased estimators of that parameter (or function of parameters), then the estimator is the best unbiased (or most efficient) estimator for that parameter (or function of parameters).

TipDefinition: Bias

Let \(\hat\theta\) be an estimator for a parameter \(\theta\). The bias of \(\hat\theta\) is

\[\hbox{Bias}(\hat\theta) = \hbox{\hspace{50mm}}\]

An estimator whose bias is 0 (i.e., E(\(\hat\theta\)) = \(\theta\)) is an unbiased estimator for \(\theta\).

It turns out these two properties (bias and variance) can be combined into a single measure: the mean-square error.

TipDefinition: Mean-square error

If \(\hat\theta\) is an estimator of \(\theta\), the mean-square error of \(\hat\theta\) is: \[\hbox{MSE}(\hat\theta) = \hbox{\hspace{60mm}}\]

The MSE has the following property: \[\hbox{MSE}(\hat\theta) = \hbox{Var}(\hat\theta) + [\hbox{Bias}(\hat\theta)]^2\]

Proof:

















If an estimator is unbiased, the MSE is equal to the variance.

Example: Suppose \(Y_1,Y_2,Y_3\) are iid Uniform\((0,\theta)\) random variables. Consider the following estimators of \(\theta\): \(\hat\theta_1 = Y_1\), \(\hat\theta_2 = 2Y_1\), \(\hat\theta_3 = Y_1 + Y_2\), \(\hat\theta_4 = Y_{(n)}\), \(\hat\theta_5= \bar Y\).

3.2.1 Data Reduction

The distributions we’ve discussing are parametric statistical models, \(f(x;\theta)\). That is, the random variable \(X\) has a distribution which depends on an unknown parameter \(\theta\) (possibly vector-valued).

  • Typically, we collect a random sample \(X_1,\dots, X_n\), and the information in the observed values \(\{x_1,\dots, x_n\}\) is used to make inferences/decisions about \(\theta\)
  • The random variables \(X_1,\dots, X_n\) contain information relevant to estimating \(\theta\), but may also contain information that is irrelevant for estimating \(\theta\)
  • Often a summary statistic \(T(X_1,\dots, X_n)\) is computed from the random sample, and we hope that \(T(\mathbf{X})\) will be useful in making inferences about \(\theta\)
  • Summary statistics are most useful if they contain all information relevant to \(\theta\), but toss out the irrelevant information
  • A summary statistic is a sufficient statistic if a statistician who knows the value of \(T(\mathbf{X})\) can do just as good a job of estimating the unknown parameter \(\theta\) as a statistician who knows the observed values of the entire random sample.







3.2.1.1 Sufficiency

TipDefinition: Sufficiency principle

A statistic \(T(\mathbf{X})\) is a sufficient statistic for \(\theta\) if the conditional distribution of the sample \(\mathbf{X}\) given \(T(\mathbf{X})\) does not depend on \(\theta\). If \(T(\mathbf{X})\) is a sufficient statistic for \(\theta\), then any inference about \(\theta\) should depend on the sample \(\mathbf{X}\) only through the value \(T(\mathbf{X})\).

  • Discrete Distributions

    The statistic \(T(\mathbf{X})\) is a sufficient statistic for \(\theta\) if and only if \[P(X_1=x_1,\dots, X_n=x_n|T(\mathbf{X})=t) = \frac{P(X_1=x_1,\dots, X_n=x_n, T(\mathbf{X})=t)}{P(T(\mathbf{X})=t)}\] does not depend on \(\theta\)

  • Continuous Distributions

    Let \(f(\mathbf{x};\theta)\) be the joint pdf of \((X_1,\dots, X_n)\) and let \(q(T(\mathbf{X});\theta)\) be the pdf of \(T(\mathbf{X})\). The statistic \(T(\mathbf{X})\) is a sufficient statistic for \(\theta\) if and only if \(\frac{f(\mathbf{x};\theta)}{q(T(\mathbf{X});\theta)}\) does not depend on \(\theta\).

3.2.1.2 Completeness

So far, we’ve talked about a few desirable properties of estimators: unbiasedness and sufficiency. We’re still on the hunt for a “best” unbiased estimator: a UMVUE. We talked earlier about the fact that UMVUEs have the smallest variance possible for an estimator of a particular parameter (or function of parameters). Sufficiency (and, more specifically, completeness) help us in the search for the minimum variance estimator. How do we know if a statistic is complete?

TipDefinition: Complete statistic

Let \(f(t;\theta)\) denote the family of pdfs/pmfs of a statistic \(T(\mathbf{X}) = T(X_1,\dots,X_n)\). The family of probability distributions is called complete if E\([g(T)] = 0\) for all \(\theta\) implies that P\((g(T)=0)=1\) for all \(\theta\). Equivalently, \(T(\mathbf{X})\) is called a complete statistic.

This might be the strangest definition we’ll see all semester! It’s saying that, if a statistic is complete, then any unbiased estimator of 0 based on that statistic should be 0 itself. What?!?!? Why do we care about unbiased estimators of 0? Here’s why we want the best estimator (the UMVUE). Completeness ensures we end up with the UMVUE, not a UMVUE. Basically, if a statistic is complete, then 2 different functions of \(T\) cannot have the same expected value.

3.3 Sufficiency, Completeness, and Best Estimation

Our goal (still!) is to use \((X_1,\dots, X_n)\) to find the best (i.e., smallest variance) unbiased estimator for an unknown parameter \(\theta\) (or function of parameters). It turns out that sufficiency and completeness help us achieve this goal.

TipTheorem: Lehmann-Scheffè

Let \(U\) be a complete sufficient statistic for \(\theta\) and let \(T(U)\) be any estimator based only on \(U\). Then \(T(U)\) is the unique, best unbiased estimator (UMVUE) of \(\tau(\theta) = \hbox{E}[T(U)]\).










FINALLY, we have a method for obtaining a best unbiased estimator:

\(\hspace{20mm}\) COMPLETENESS + UNBIASED ESTIMATOR = UMVUE

Example: Let \(X_1,\dots, X_n\) be iid Binomial\((m,p)\) RVs. We want the UMVUE of \(p\).










Example: Let \(X_1,\dots, X_n\) be iid N\((\mu,1)\) RVs. We want the UMVUE of \(\mu^2\).





















Example: Let \(X_1,\dots, X_n\) be iid Geometric\((p)\). We want the UMVUE of \(p\).


















What if we can’t find an unbiased estimator based on the complete sufficient statistic?

TipTheorem: Rao-Blackwell + Lehmann-Scheffè

Let \(U\) be a complete sufficient statistic for \(\theta\), and let \(h(X_1,\dots, X_n) = h(\mathbf{X})\) be any unbiased estimator of \(\tau(\theta)\). Then \[ T(U) = \hbox{E}[h(\mathbf{X})|U] \] is the UMVUE of \(\tau(\theta)\).
